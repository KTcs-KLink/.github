# KTcs K-Link 협업 규칙

이 저장소는 `KTcs-KLink` 조직의 공통 협업 규칙과 GitHub 템플릿을 관리합니다.

## 프로젝트 저장소

- [`ai-assistant`](https://github.com/KTcs-KLink/ai-assistant): 사용자 화면, Assistant 서버·오케스트레이터 및 MCP Client
- [`knowledge-mcp`](https://github.com/KTcs-KLink/knowledge-mcp): 업무지식 데이터·청크, 검색 및 MCP Server

## 시작하기

1. 작업을 시작하기 전에 GitHub Issue에서 할 일을 확인하거나 등록합니다.
2. `main`에서 작업 브랜치를 만들고, 작업이 끝나면 Pull Request(PR)를 엽니다.
3. 팀원 1명의 리뷰를 받고 PR을 병합합니다.
4. 작업 내용과 사용 방법은 해당 프로젝트 저장소의 README와 문서에 기록합니다.

공통 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.
