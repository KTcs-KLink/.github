# KTcs K-Link

KTcs 업무지식 검색·활용 Assistant 프로젝트를 진행하는 팀 공간입니다.

## 저장소

- **ai-assistant**: 사용자가 질문하고 답변과 출처를 확인하는 Assistant 화면
- **knowledge-mcp**: MCP 연동과 공개·승인된 지식 문서 및 청크 데이터
- **.github**: 저장소 공통 협업 규칙과 PR·이슈 템플릿

## 협업

작업은 Issue와 브랜치로 나누고, `main`에 바로 커밋하지 않습니다. 변경 사항은 PR로 공유하고 팀원 1명의 리뷰 후 병합합니다. 자세한 규칙은 [.github 협업 가이드](https://github.com/KTcs-KLink/.github/blob/main/CONTRIBUTING.md)를 따릅니다.
